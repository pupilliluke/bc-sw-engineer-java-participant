1, REPO STUB THROWS ON SAVE

A temporary ExperimentOneTest built CustomerService over an anonymous
CustomerRepository whose save throws IllegalStateException("repository
unavailable").

  mvn -B test -Dtest=ExperimentOneTest

  [INFO] Tests run: 1, Failures: 0, Errors: 0, Skipped: 0 -- in com.northstar.crm.ExperimentOneTest

create propagated the repository failure with its message intact instead of
turning it into a duplicate or swallowing it. The service adds a rule on top of
the repository and does not catch what the repository throws. Test file deleted
after the run.


2, ILLEGAL STATUS TRANSITION

  curl -s -X PATCH http://localhost:8080/api/customers/CUS-1001/status -H "Content-Type: application/json" -H "X-Correlation-Id: lab-request-001" -d "{\"status\":\"PROSPECT\"}"

  {"timestamp":"2026-08-06T21:37:54.661+00:00","status":500,"error":"Internal Server Error","path":"/api/customers/CUS-1001/status"} HTTP 500

  server log: illegal status transition ACTIVE -> PROSPECT [lab-request-001]

  curl -s http://localhost:8080/api/customers/CUS-1001

  {"id":"CUS-1001","name":"Amina Khan","email":"amina.khan@example.com","status":"ACTIVE"}

Rejected and unchanged. The check runs before setStatus, so nothing was written
and the read after it still says ACTIVE.

CLOSED is terminal on the same table.

  CUS-1002 ACTIVE -> CLOSED   HTTP 200
  CUS-1002 CLOSED -> ACTIVE   HTTP 500
  server log: illegal status transition CLOSED -> ACTIVE [lab-request-001]

  {"id":"CUS-1002","name":"Ravi Singh","email":"ravi.singh@example.com","status":"CLOSED"}

The 500 body carries no message. The from, the to and the correlation id are in
the exception and reach the log only, so the caller cannot tell this apart from
the CUS-9999 not-found without reading the server side. Lab 29 is where that
becomes a 409 with a body.
