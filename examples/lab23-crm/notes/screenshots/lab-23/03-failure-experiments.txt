1, REMOVE THE WEB STARTER

  <!--
      <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
      </dependency>
  -->

  mvn -B clean compile

  [ERROR] COMPILATION ERROR :
  [ERROR] .../api/CustomerController.java:[5,32] package org.springframework.http does not exist
  [ERROR] .../api/CustomerController.java:[6,1] package org.springframework.web.bind.annotation does not exist
  [ERROR] .../api/CustomerController.java:[8,2] cannot find symbol
  [ERROR] .../api/CustomerController.java:[17,4] cannot find symbol

It never reaches a context or a missing embedded server: spring-web and
spring-webmvc arrive only through starter-web, so @RestController,
@RequestMapping and HttpStatus stop resolving at javac. Actuator stays on the
classpath and does not bring them. Starter restored.

4, PORT ALREADY IN USE

  java -jar target\lab23-crm-0.0.1-SNAPSHOT.jar   (with spring-boot:run still on 8080)

  ***************************
  APPLICATION FAILED TO START
  ***************************

  Description:

  Web server failed to start. Port 8080 was already in use.

  Action:

  Identify and stop the process that's listening on port 8080 or configure this application to listen on another port.

Boot's failure analyzer turns the BindException into the port message and the
action line. Fixed 8080 comes from application.yml, which is why the HTTP test
uses RANDOM_PORT.
