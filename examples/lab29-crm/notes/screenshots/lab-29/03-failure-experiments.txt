Fixed message in the body, class name and stack in the log only. Fallback kept.

The exception is HttpMessageNotReadableException, which Boot answers with 400 on
its own. @ExceptionHandler(Exception.class) is wider than unhandled and takes it
first, so a malformed body reads as a server fault to the client. The GUIDE's
timed map is MethodArgumentNotValid 400, IllegalArgument 404, IllegalState 409
and Exception 500, and it is left as written. A handler for that type is what
would move the case back to 400.
