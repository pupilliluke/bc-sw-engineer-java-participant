ProfileBindingTest is @SpringBootTest with @ActiveProfiles("test"). It asserts
connectTimeoutMs 100 and apiBaseUrl http://localhost:9090 off the bound
NorthstarIntegrationProperties, then reads CUS-1001 Amina Khan from
CustomerService.

The @ActiveProfiles annotation is what forces the test profile. Without it the
suite would pick up spring.profiles.default and bind 2000 from the base file
instead of 100.

The log line comes from an ApplicationRunner in CrmApplication. It prints the
active profiles, apiBaseUrl and connectTimeoutMs, and a boolean for whether the
api key is set rather than the key itself. It is how the override ladder in
03-failure-experiments.txt was measured.
