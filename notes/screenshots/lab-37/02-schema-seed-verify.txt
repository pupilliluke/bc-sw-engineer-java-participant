5. Indexes are used

  EXPLAIN (COSTS OFF) SELECT * FROM account WHERE customer_id = 1;
   Index Scan using ix_account_customer on account
     Index Cond: (customer_id = 1)

  EXPLAIN (COSTS OFF)
  SELECT * FROM customer_status_history WHERE customer_id = 1 ORDER BY changed_at;
   Index Scan using ix_history_customer_time on customer_status_history
     Index Cond: (customer_id = 1)

PostgreSQL indexes a PRIMARY KEY and a UNIQUE automatically but never a
foreign key, so these three are the ones the DDL has to create. The
history index is (customer_id, changed_at) so the timeline comes back
ordered without a sort.
